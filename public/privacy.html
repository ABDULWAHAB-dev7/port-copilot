Privacy

Draft for review. This text describes how the code behaves today. It must be reviewed by counsel before it is relied on.

What the service receives

The tools receive the text you type or paste: an officer's question, a shipment selection, an optional tariff card name, and invoice text for the charge check.

What is stored

The API keeps no state between requests. It reads only the sample data bundled with the application. Requests are not written to a database by this code. The hosting provider may keep its own request logs, under its own policy.

AI drafting

AI drafting is off unless you tick the option and the operator has configured a model key. When it is on, the question you asked and the document lines matched to it are sent to the model provider, Google Gemini, to produce a proposed draft. The proposal is checked against the document lines before you see it. Sentences that fail the check are removed.

Personal data

The sample shipments, invoices and tariff cards are synthetic. Do not enter real personal, customer or shipment data unless the operator has confirmed in writing that this is allowed.
